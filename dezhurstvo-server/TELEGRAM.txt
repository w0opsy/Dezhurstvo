ДЕЖУРСТВО В TELEGRAM: ВХОД ЧЕРЕЗ TELEGRAM И ОБЩИЙ РЕЙТИНГ

Как это устроено
 • Игрок нажимает «Играть» в боте — игра открывается внутри Telegram и сразу знает, кто он
   (имя и аватарка из Telegram, никаких паролей).
 • Результаты уходят на ваш сервер, там же общий рейтинг всех игроков бота.
 • Сервер проверяет подпись Telegram, поэтому зайти под чужим именем или накрутить чужой счёт нельзя.
 • Бот отвечает на /start (кнопка игры), /top (рейтинг прямо в чате), /help.

Почему нужен сервер
 GitHub Pages только раздаёт файлы — хранить общий рейтинг он не умеет. Без сервера игра в Telegram
 работает, но у каждого виден только свой прогресс.

──────────────────────────────────────────────
УСТАНОВКА (≈15 минут, один раз)

1. Токен бота
   @BotFather → /mybots → ваш бот → API Token. Строка вида 123456789:AAH...  Никому не показывайте.

2. VPS
   Любой российский хостинг: Timeweb Cloud, Beget, Selectel, REG.RU — самый дешёвый тариф
   (1 ядро, 1 ГБ RAM, ~200–300 ₽/мес), система Ubuntu 22.04 или 24.04.
   После создания хостинг пришлёт IP и пароль root.

3. Загрузите папку dezhurstvo-server на сервер. Один из способов:
   а) Windows — программа WinSCP: подключиться к IP под root, перетащить папку в /opt
   б) терминал на компьютере:   scp -r dezhurstvo-server root@IP_СЕРВЕРА:/opt/
   в) если папка лежит в вашем репозитории GitHub — на сервере:
         git clone https://github.com/ВАШ_НИК/РЕПОЗИТОРИЙ /opt/dezh  (папка сервера будет внутри)

4. Подключитесь к серверу (Windows: PowerShell или PuTTY; на телефоне — Termius):
         ssh root@IP_СЕРВЕРА

5. Запустите установку, подставив свой токен:
         cd /opt/dezhurstvo-server
         bash install.sh 123456789:AAH...ваш_токен

   Скрипт сам поставит Node.js и Caddy, получит HTTPS-сертификат, запустит игру и бота
   и напишет адрес игры — вида https://1-2-3-4.sslip.io/ (домен покупать не нужно).
   Если есть свой домен с A-записью на IP сервера — добавьте его вторым параметром:
         bash install.sh ТОКЕН игра.мойдомен.ru

6. Откройте бота в Telegram → /start. Кнопка «Играть» уже ведёт на сервер.
   Если раньше в @BotFather ставили ссылку на GitHub Pages — сервер заменит её сам.
   Если делали /newapp (ссылка t.me/бот/game): @BotFather → /myapps → ваше приложение →
   Edit Web App URL → вставьте новый адрес.

7. (по желанию) Вход через Telegram в обычном браузере (кнопка «Войти через Telegram» на сайте):
   @BotFather → /setdomain → ваш бот → адрес сервера без https:// (например 1-2-3-4.sslip.io).
   Аккаунт и рейтинг те же, что в боте.

Друзьям — ссылка t.me/имя_бота или кнопка «Позвать друга» на главном экране игры.


──────────────────────────────────────────────
ИГРА НА GITHUB PAGES + РЕЙТИНГ НА СЕРВЕРЕ (если игроки сидят с VPN)
Зачем: фильтрация «душит» тяжёлые загрузки между российским сервером и зарубежными VPN.
Тяжёлый файл игры отдаёт GitHub (открывается и с VPN, и без), а сервер — только маленькие ответы
рейтинга и сохранений. Если связи с сервером нет, игра работает дальше: рейтинг показывается
из сохранённой копии, результаты ждут в очереди и отправляются сами, когда связь появится.

1. GitHub: в корне репозитория должен лежать index.html (это dezhurstvo.html из архива).
   Адрес игры — Settings → Pages, например https://w0opsy.github.io/Dezhurstvo/
2. На сервере обновите файлы сервера (server.js, bot.js) и добавьте два адреса:
      cat >> /etc/dezhurstvo.env <<'X'
      PUBLIC_URL=https://79-174-78-227.sslip.io/
      GAME_URL=https://w0opsy.github.io/Dezhurstvo/
      X
      systemctl restart dezhurstvo
   (при новой установке то же самое делает:  bash install.sh ТОКЕН - https://w0opsy.github.io/Dezhurstvo/ )
3. Бот сам поставит кнопку «Играть» на  GAME_URL?api=PUBLIC_URL . Если делали /newapp — в @BotFather
   → /myapps → Edit Web App URL вставьте этот же адрес целиком (его печатает журнал: journalctl -u dezhurstvo -n 5).

──────────────────────────────────────────────
ОБСЛУЖИВАНИЕ
 Обновить игру:     заменить файл /opt/dezhurstvo-server/public/index.html новым
                    (перезапуск не нужен, у игроков обновится при следующем открытии)
 Обновить сервер:   заменить server.js / bot.js и выполнить  systemctl restart dezhurstvo
 Логи:              journalctl -u dezhurstvo -n 50
 Бэкап рейтинга:    /opt/dezhurstvo-server/data/db.json  — скачивайте иногда через WinSCP

Если что-то не работает
 • «Бот: fetch failed» в логах — сервер не достучался до api.telegram.org; у некоторых хостингов
   бывает, подождите или смените хостинг/регион.
 • Игра не открывается по https — подождите 1–2 минуты (сертификат), проверьте journalctl -u caddy -n 30.
 • Sslip-сертификат не выдаётся — купите домен (~200 ₽/год) и укажите его вторым параметром.

──────────────────────────────────────────────
БЕЗ СЕРВЕРА (вариант на пробу)
 Игра на GitHub Pages + ссылка в @BotFather → Bot Settings → Menu Button.
 Вход через Telegram работает, прогресс хранится в облаке Telegram у каждого игрока,
 но общего рейтинга нет, и бот на сообщения не отвечает.
